# Phase 0 readiness record

Status: materially prepared, exit gate not yet passed

Reviewed: 2026-08-04 against current `origin/main` production truth and the
2026-08-04 founder direction

## Prerequisites already satisfied

- `FOUNDER_DOCTRINE.md`, `docs/GROWTH_ROADMAP.md`, product, security,
  distribution, repository, and machine-readable durable-moat contracts agree
  that local roadmap work is authorized and external activation remains gated.
- The canonical publication remains intact: politics-free news and Scripture in
  the morning, the evening Field Guide of useful tools and repeatable workflows,
  the website, archive, RSS, edition paths, source evidence, corrections, and
  **Loved by God**.
- The official first-1,000 definition is specified. The audience baseline is
  plainly `not-measured`, unknown rather than zero, and the checked-in adapter
  is disabled with no endpoint. The Cloudflare implementation and canary remain
  local and unprovisioned.
- The site-side reader-intake closure is production truth. Public submission and
  newsletter collection controls are absent, Counter sync is a retained no-op,
  `counter.csv` is absent at the repository tip, and the four Chronicles exports
  remain available.
- Security, privacy, incident, deletion, portability, audience, reader-store,
  publisher-identity, and roadmap boundaries exist in version-controlled specs
  and contracts. The installable-web-app architecture is recorded separately in
  `docs/PWA_ARCHITECTURE.md`.

## Material remaining gaps

1. There is no complete row-by-row register for every proposed account,
   personal-history, prayer, relationship, moderation, and reputation data
   class naming its purpose, owner, retention, deletion, export, and prohibited
   uses. General law exists, but the Phase 0 evidence requirement is more
   specific.
2. Future participation surfaces do not yet have named moderation roles,
   response expectations, escalation coverage, surface-specific kill switches,
   and reviewed no-continuous-monitoring notices in one operating plan.
3. The legacy external Counter/Sheet boundary and repository history retain
   reader-data exposure beyond the target design. The tip-level site closure
   limits new exposure, but the private store is unprovisioned and external
   provider, migration, deletion, and history actions remain separately gated.
4. The protected publisher identity and `main` ruleset are designed but not
   provisioned. Production still uses the documented built-in-token exception,
   so no new live personal-data surface should be added before that boundary is
   closed and independently reviewed.

The unknown audience baseline is not a remaining Phase 0 gap because the
roadmap explicitly permits it to be recorded as unknown. This record does not
authorize a canary, deployment, provider action, credential, live data
collection, or community activation.
