A free duplicate finder cleared 900GB off one home server, and it runs on Windows, Mac and Linux

Storage fills up quietly, and the second copy of everything you own is usually the reason.

Krokiet is the new graphical front end for Czkawka, a Rust cleanup engine that matches exact duplicates by hash and also finds empty folders, oversized files, similar images and similar videos. It is free and open source, with the Krokiet interface under GPL-3.0 and the shared core under MIT, it runs on Linux, macOS, Windows and FreeBSD across x86, ARM and RISC-V, and the repository currently shows 33.9k stars. Writing for XDA on October 6, Anurag Singh pointed it at a 10TB home server over network shares from a Mac, finished the scan in roughly 36 minutes, and removed about 900GB of redundant files. He reviewed every result before deleting anything and marked reference folders so chosen backups stayed untouched, and he notes that the Similar Videos check needs FFmpeg and that files read over a network take longer to scan.

The tool shelf new tonight

Krokiet (Czkawka)

Free, GPL-3 with MIT coreWindows, macOS, Linux, FreeBSDXDA Developers, Oct 6

Scans a drive or a network share for exact duplicates by hash, then adds empty folders, big files, temporary files, similar images and similar videos, and lets you mark reference folders so a backup you want kept is never offered up for deletion, though XDA's Anurag Singh reviewed every result by hand before removing anything, the Similar Videos check needs FFmpeg installed, and files read over a network take noticeably longer to scan.

PDFgear

Free, no sign-upWindows, Mac, iOS, Android, webXDA Developers, Oct 6

Edits PDF text and images, merges, splits and reorders pages, converts to and from Word, Excel, PowerPoint and JPG, reads scans with OCR in more than 30 languages and signs documents, free across desktop, mobile and the browser with no account required, with the one caveat that its AI summarizing is a ChatGPT integration rather than an offline feature, so that part of the work runs through an outside service.

Flow Launcher

Free and open sourceWindows 10 and laterXDA Developers, Oct 6

Press Alt+Space and one box searches your apps, files and file contents, browser bookmarks and Windows settings, runs a calculator, a web search or a shell command, and accepts plugins written in C#, F#, Python, JavaScript or TypeScript, with the plain limit that the project supports Windows 10 and later only, so a Mac or Linux machine needs a different launcher.

System Informer

Free, MIT licensedWindows 10 or later, portableMakeUseOf, Oct 6

A portable Task Manager replacement that needs no installation and shows processes as a parent and child tree with color coding, live network and disk activity named process by process, and a handle search on Ctrl+F that finally tells you which program is holding the file you cannot delete, though MakeUseOf's Kanika Gogia found the interface unpolished and crowded with columns and tabs next to Task Manager, and warns that changing a priority or ending the wrong tree can break something.

One drop-down and a FILTER formula replace the worksheet you were keeping for every region

An hour, start smallExcel for Microsoft 365How-To Geek front, Oct 6

Format the data as a table How-To Geek's Tony Phillips presses Ctrl+T so the range answers to a name like tblSales, names the Region column in Name Manager so data validation can reach it from another sheet, drops a validation list into cell B3, then writes =FILTER(tblSales,tblSales[Region]=B3) to pull back only the matching rows, multiplying two conditions with an asterisk when both must be true and adding them with a plus sign when either will do; he notes the formula needs Excel for Microsoft 365, that anything parked where the results spill returns a #SPILL! error, and that totals and counts are still better served by a PivotTable with slicers.

Six Bitwarden settings that tighten autofill before it offers a password to the wrong page

About twenty minutesA Bitwarden accountMakeUseOf front, Oct 6

Start inside autofill MakeUseOf's Afam Onyimadu switches on master password re-prompt for individual items from the three-dot Edit screen, turns off automatic TOTP copying under Settings and Autofill, leaves Autofill on page load unchecked because an untrusted site can exploit it, changes default URI match detection to Host so one login stops appearing across every subdomain, adds the sites he never wants touched to Blocked domains, and moves key derivation from PBKDF2 to Argon2id in the web vault, noting that the re-prompt is an interface guardrail rather than encryption and that PBKDF2 is still the better answer where FIPS 140-2 compliance matters.

Capture in RAW, keep one master, and export JPEG, PNG or WebP only when it is time to send

Half an hour to set upA camera or phone that shoots RAWMakeUseOf front, Oct 6

Separate working from delivery MakeUseOf's Yadullah Abidi treats RAW and TIFF as archives rather than things you hand to anyone, edits without overwriting the source so a high-quality master survives, exports JPEG for finished photographs that have to travel by email or upload, saves screenshots, logos and diagrams as PNG because that is where exact pixels matter rather than wherever maximum quality sounds safest, and reaches for WebP or AVIF when the destination is a web page, with the warning that a JPEG already thinned by repeated edits cannot be repaired by converting it to PNG.

Six things Google Drive already does, from scanning a receipt to restoring last week's draft

Half an hourA Google Drive accountAndroid Police front, Oct 6

Scan, then search the text Android Police's Anu Joy taps the plus button and picks Scan so a receipt or form becomes a cropped PDF, leans on Drive's text recognition to find words inside images and scanned PDFs instead of guessing at filenames, opens a PDF in Google Docs from the desktop right-click menu to pull out editable text, restores an earlier draft from File and Version history with its timestamp and editor name, writes a short note under File information and Details so a shared folder explains itself, marks what she needs available offline, and narrows the search by type, owner, location, date and collaborator; her one caution is that the text recognition is not flawless, though it is often surprisingly accurate on typed documents.
